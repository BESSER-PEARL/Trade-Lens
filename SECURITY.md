# Security Policy

This is a hackathon prototype and is not intended for production use.

If you find a security issue, please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/BESSER-PEARL/statec_hackathon_2026/security/advisories/new)
or by contacting the maintainers listed in the [README](README.md#team).

The repository must never contain credentials, API keys or personal data. Local secrets belong in
`.env` files, which are git-ignored.
